# Tic-Tac-Toe: No Draws

An AI-assisted exploration and implementation of a two-player Tic-Tac-Toe variant in which games can never end in a draw and always terminate.

## Overview
Built with vanilla HTML, CSS, and JavaScript. No build step required.

To run locally:
```bash
python -m http.server 8000
```
Open `http://localhost:8000` in Google Chrome.

## Project Structure
- `index.html`: Playable game interface
- `style.css`: UI styling
- `src/`: Game logic & state machine
- `docs/RULES.md`: Plain-English game rules
- `docs/DESIGN.md`: Design rationale, proofs / state space search, rejected variants
- `transcript/`: Raw AI session logs, environment configs, and tooling documentation
