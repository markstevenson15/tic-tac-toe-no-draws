TOROIDAL TIC-TAC-TOE

A mathematical two-player variant with zero draws

X Turn: Player X

Toroidal (12 Lines)

Game Rules & Mathematical Proof

1. The Core Invariants

This variant is designed to strictly satisfy two mathematical conditions:

  • No Draw: There is no terminal state in which neither player has won.
  • Always Terminates: Every line of play terminates in at most 9 moves.

2. Toroidal Topology (12 Winning Lines)

In addition to the 3 rows, 3 columns, and 2 classic diagonals, opposite edges wrap around like a 2D torus (affine plane AG(2,3)). This introduces 4 wrap-around diagonals.

Wrap Diagonals:
• (0,1) → (1,2) → (2,0)
• (0,2) → (1,0) → (2,1)
• (0,0) → (1,2) → (2,1)
• (0,1) → (1,0) → (2,2)

3. The Center-Square Tie-Breaker

If all 9 cells are filled and neither player has achieved 3-in-a-row (such as in standard non-wrap play), the player holding the Center Square (1,1) Anchor is declared the winner immediately.

4. Mathematical Proof (Cap Set Theorem)

On a 3×3 Torus (AG(2,3)), the maximum size of a cap (a subset with no 3 collinear points) is 4. Any 5 points must contain at least one line of 3. Because Player X places 5 pieces by move 9, Player X is mathematically guaranteed a line if Player O has not already won.
